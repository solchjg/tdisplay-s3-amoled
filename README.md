# T-Display-S3 Webserver

Webserver firmware for the LilyGO T-Display-S3 (ESP32-S3), built with ESP-IDF
v6.0.2 and verified on the Embedded AI Harness testbench.

**Status: defined, not yet built.** The FSD specifies a WiFi station with a
provisioning portal, a status page and JSON API, HTTP OTA with rollback, and a
display that shows the IP address and request count. The firmware in this repo
still runs the `tdisplay-s3-hello` display until the webserver is built.

Documentation: [`docs/00-Overview.md`](docs/00-Overview.md).
