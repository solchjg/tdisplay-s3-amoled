# T-Display-S3 Webserver

Webserver firmware for the LilyGO T-Display-S3 (ESP32-S3), built with ESP-IDF
v6.0.2 and verified on the Embedded AI Harness testbench.

**Status: not yet defined.** The project starts from the `tdisplay-s3-hello`
base (board bring-up, ST7789 LCD driver, serial log, CI, bench scaffolding); the
firmware still runs the hello display until the webserver is specified and built.

Documentation: [`docs/00-Overview.md`](docs/00-Overview.md).
